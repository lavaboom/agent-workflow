# Tasks

This project's tasks follow the shared workflow: the layout, the names, the files in a task folder and how to
link to them are in `C:/code/agent-workflow/TASKS.md`; how agents claim, build, review and close a task is in
`C:/code/agent-workflow/AGENT_PROTOCOL.md`; which tasks exist and their status is in `docs/ROADMAP.md`.

```
docs/tasks/
  active/<task>/       not done yet: BACKLOG through REVIEW, or BLOCKED
  completed/<task>/    DONE (merged into master) or DROPPED (not needed; status.md says why)
```
