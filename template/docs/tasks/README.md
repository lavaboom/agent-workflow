# Tasks

This project's tasks follow the harness in `docs/harness/`: the layout, names and files of a task folder,
and how agents claim, build, review and close a task, are in `docs/harness/task-flow.md`; the `status.md`
format is `docs/harness/status-template.md`; which tasks exist and their status is in `docs/ROADMAP.md`.

```
docs/tasks/
  active/<task>/       not done yet: BACKLOG through REVIEW, or BLOCKED
  completed/<task>/    DONE (merged into master) or DROPPED (not needed; status.md says why)
```
