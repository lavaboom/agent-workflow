# Lessons for the planner

The persistent memory of what plans must contain for a weaker builder to finish first pass
(`docs/harness/model-policy.md` → Lessons). Read before writing a plan. One dated paragraph per lesson:
what was missing, what the plan says next time. Written when a `fix`, `escalated` or `blocked` ledger row
has layer `spec` or `context`, and at the weekly review. Retired lessons move to the bottom with the date.
